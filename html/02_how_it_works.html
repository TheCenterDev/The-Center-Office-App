Using this app

This launcher lives on your desktop (or in your Applications folder on Mac). Guides like this one open right inside the app; interactive tools — marked with ↗ in the sidebar, or listed together on the Apps page — open in their own window since they need a real browser to run. If you don't see a document you're expecting, ask an admin to add it to the html folder, then click Refresh at the bottom of the sidebar.
